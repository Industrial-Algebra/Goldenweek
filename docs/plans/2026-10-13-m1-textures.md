**(d) Texture inner + drop.** Add (top-level in `src/vulkan.rs`, near
`VulkanPipelineInner`):

```rust
/// Owning handle for an M1 texture's GPU resources. `raw` is what
/// `Texture::raw` carries (boxed); the drop function destroys in
/// dependency-safe order: view, sampler, image, memory, then the
/// descriptor pool (which frees its sets) and the staging-free state.
pub(crate) struct VulkanTextureInner {
    pub view: vk::ImageView,
    pub sampler: vk::Sampler,
    pub image: vk::Image,
    pub memory: vk::DeviceMemory,
    pub pool: vk::DescriptorPool,
    pub set: vk::DescriptorSet,
    pub width: u32,
    pub height: u32,
}

pub(crate) fn vulkan_texture_drop(raw: *mut c_void) {
    // Safety: `raw` was produced by `Box::into_raw::<VulkanTextureInner>`
    // in `create_texture` and the backend (device) is still alive — the
    // handle type documents the outlive contract.
    unsafe {
        let inner = Box::from_raw(raw as *mut VulkanTextureInner);
        // leak-safe: no DeviceWaitIdle here — the synchronous present
        // contract guarantees in-flight frames completed (same argument
        // as GpuBuffer).
        let dev = inner_device_clone_for_drop(); // see note below
        dev.destroy_image_view(inner.view, None);
        dev.destroy_sampler(inner.sampler, None);
        dev.destroy_image(inner.image, None);
        dev.free_memory(inner.memory, None);
        dev.destroy_descriptor_pool(inner.pool, None);
    }
}
```

NOTE — the drop function needs an `ash::Device`. Follow EXACTLY the
pattern `GpuBuffer` uses for its drop fn (`src/lib.rs` documents it:
a `Box<zunesha::Buffer>` needs no device — but a texture does). Use the
same solution `VulkanPipelineInner`'s drop path uses (inspect how
pipeline drop obtains the device — `RenderPipeline`'s `drop_fn`).
Mirror it: store an `ash::Device` clone inside `VulkanTextureInner` and
use it in the drop fn (ash `Device` is an Arc'd handle — cloning is the
established pattern in this file for `VulkanBackend`).

**(e) `create_texture`** — add as `pub fn` on `VulkanBackend` (near
`create_buffer`):

```rust
    /// Create an immutable RGBA8 texture and upload `data` — M1.
    ///
    /// One call, one state machine: validate → stage → create image
    /// resources → upload (synchronous submit-and-wait on the graphics
    /// queue via a transient pool) → build the descriptor set. The
    /// texture is immediately sampleable when this returns.
    pub fn create_texture(
        &self,
        desc: &TextureDesc,
        data: &[u8],
        filter: FilterMode,
    ) -> Result<Texture> {
        desc.validate(data).map_err(|e| GraphicsError::InvalidArgument {
            message: e.to_string(),
        })?;
        // NOTE: `validate` returns the expected length — re-read it via
        // `desc.validate(data)` result if needed; do NOT re-derive.

        // 1. Staging: host-visible, TRANSFER_SRC. Hand-rolled (a
        //    transient internal detail — the zunesha::Buffer seam stays
        //    for compute-shared buffers).
        //    - vkCreateBuffer (size = data.len(), usage TRANSFER_SRC)
        //    - memory type: HOST_VISIBLE | HOST_COHERENT
        //    - allocate + bind + map + copy + unmap
        //    On ANY failure: destroy the buffer and free the memory
        //    (allocation-failure cleanup discipline, Zunesha 0.1.2).

        // 2. Image + memory + view + sampler:
        //    - vkCreateImage: R8G8B8A8_UNORM, extent desc, usage
        //      TRANSFER_DST | SAMPLED, tiling OPTIMAL, type 2D,
        //      mips=1, array=1, samples 1, CONCURRENT families
        //      [graphics] (query self's queue family index field).
        //    - memory requirements → memory type DEVICE_LOCAL
        //    - allocate, bind.
        //    - ImageView: type 2D, format as image, subresource
        //      COLOR, aspect COLOR, base 0, levels 1, layers 1.
        //    - Sampler: mag/min from `filter` (NEAREST or LINEAR),
        //      mip LINEAR is fine (no mips sampled), address U/V/W =
        //      CLAMP_TO_EDGE, unnormalizedCoordinates FALSE,
        //      compareEnable FALSE, maxLod 0.0, maxAnisotropy 1.0
        //      (anisotropy DISABLED).
        //    On ANY failure after image creation: destroy everything
        //    created before it (view → sampler → image → memory →
        //    staging), then return TextureCreate/TextureUpload.

        // 3. Upload (synchronous, one-shot, transient pool + fence):
        //    - vkCreateCommandPool (TRANSIENT, graphics queue family)
        //    - allocate 1 primary buffer, begin (OneTimeSubmit)
        //    - barrier: UNDEFINED → TRANSFER_DST_OPTIMAL,
        //      srcStages TOP_OF_PIPE (or ALL_COMMANDS — match the
        //      file's existing barrier style), srcAccess NONE,
        //      dstStages TRANSFER, dstAccess TRANSFER_WRITE, aspect
        //      COLOR, mips 1, layers 1.
        //    - vkCmdCopyBufferToImage: whole staging buffer, image,
        //      TRANSFER_DST_OPTIMAL, one region covering the extent.
        //    - barrier: TRANSFER_DST_OPTIMAL → SHADER_READ_ONLY_OPTIMAL,
        //      srcStages TRANSFER, srcAccess TRANSFER_WRITE, dstStages
        //      FRAGMENT (and ALL_GRAPHICS acceptable), dstAccess
        //      SHADER_READ, same subresource.
        //    - end; vkCreateFence (unsigenaled); queue_submit(graphics
        //      queue, [submit], fence); wait_for_fences(fence, MAX);
        //    - destroy fence, free command buffer, destroy pool.
        //    - destroy staging buffer + free staging memory.
        //    Submit/wait failures map to TextureUpload.

        // 4. Descriptor set: pool with max_sets=1, one CIS pool size,
        //    FREE_DESCRIPTOR_SET flags; allocate set from
        //    self.texture_set_layout; write image info (view, layout
        //    SHADER_READ_ONLY_OPTIMAL, sampler).
        //    Pool destruction at texture drop frees the set — no
        //    per-backend pool exhaustion state.

        // 5. Box the inner, return Texture { raw, width, height,
        //    drop_fn: vulkan_texture_drop }.
        todo!("M1: implement per contract blocks (e)-(1..5)")
    }
```
